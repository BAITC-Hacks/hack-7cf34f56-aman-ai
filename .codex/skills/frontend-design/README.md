# MoneyGraph skills

Repository copies of all four frontend skills installed for this project, including their supporting files.

| Skill | Purpose | Source |
| --- | --- | --- |
| [shadcn](shadcn/SKILL.md) | shadcn component selection and composition | [shadcn/ui](https://github.com/shadcn-ui/ui/tree/main/skills/shadcn) |
| [bklit-ui](bklit-ui/SKILL.md) | Charts and data visualization | [bklit/bklit-ui](https://github.com/bklit/bklit-ui/tree/main/skills/bklit-ui) |
| [moneygraph-frontend](moneygraph-frontend/SKILL.md) | Node Inspector, domain rules, and backend coordination | Created for MoneyGraph |
| [frontend-qa](frontend-qa/SKILL.md) | Lint, build, and Playwright browser verification | Created for MoneyGraph |

These are browsable copies. The local installations remain in place. To install on another machine, copy the desired skill directories into `~/.codex/skills/`, preserving their supporting files. MCP servers are configured separately; credentials are not included here.
